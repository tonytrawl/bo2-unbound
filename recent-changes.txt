# Black Ops 2 Unbound - Theater Mode Update

![Now you can watch yourself get shit on from every angle](https://raw.githubusercontent.com/tonytrawl/bo2-unbound/refs/heads/main/banners/Theaturemode.png)

## Your matches have an encore

**Theater Mode is here.** Record hosted matches, return to the game's familiar Theater browser, and watch them back. Save edited clips, revisit your local film library, and remove recordings you no longer want. Multiplayer and Zombies films remain separate, so each mode shows the right recordings.

*Films are stored locally on the SD card; this update does not add cloud sharing or video export.*

---

## More game, less overhead

![Treyarch didn't try, we did](https://raw.githubusercontent.com/tonytrawl/bo2-unbound/refs/heads/main/banners/Graph%20optimization.png)

The new game-code optimizations reduce work in the busiest parts of the engine. In project comparison tests, the updated build measured approximately:

- **11% higher frame rate**
- **12% lower overall CPU usage**
- **28% lower usage on the busiest CPU core**

These are test results, not a fixed boost for every map or match. Your results will vary with the scene, player count, and active mods.

## Better mixed lobbies

Host- and client-side **Lua/LUI compatibility fixes** address the different-Lua-version rejection that could keep players without Unbound out of Unbound-hosted lobbies. Friends can join on compatible maps without installing Unbound themselves. Custom maps and other gameplay assets still require the matching content on each player's console.

## The Plugin Workshop

**Unbound Mod Link** loads mods directly from SD:/unbound/content/mods into the game's mods view. No routine copy to internal storage or USB is needed. Open **Mod Manager** and press **Minus** to turn runtime linking on or off. It uses Aroma's existing ContentRedirectionModule and does not replace that shared module. Mod Link updates through HQ's verified release feed; it does not download or poll while you play.

**GamePad Mic Redirect** is an optional, experimental plugin that lets supported games use the Wii U GamePad's built-in microphone where headset voice input is normally expected. It includes **mute** and **push-to-talk** controls. Install it from Workshop, then enable its optional Auto-Update there if you want HQ to check the developer's verified release at startup. Auto-Update starts **OFF**.

Workshop opens from saved listings right away. Open a plugin for its current release and install status, or press **X** to refresh the listing. HQ can update itself and install Unbound content patches without making returning players download the full package again.
