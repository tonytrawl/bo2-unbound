# Black Ops 2 Unbound HQ v0.0.01 Beta

This is the first universal public beta for supported releases of Call of Duty: Black Ops II
on Wii U. HQ detects the installed title ID and language, so every console downloads the same
payload.

## Release assets

- `BO2-Unbound-HQ-v0.0.01.wuhb` — the Aroma homebrew application.
- `unbound-universal-0.0.01-update.zip` — shared files installed into the detected UPDATE title.
- `unbound-universal-0.0.01-aoc.zip` — shared files installed into the detected AOC title.
- `unbound-universal-0.0.01.manifest.json` — per-file sizes, routed paths, and SHA-256 values.
- `checksums.sha256` — hashes for release verification.

Both ZIP packages are required. They are separate because GitHub requires each release asset
to be smaller than 2 GiB. The HQ application downloads and verifies each component, installs
UPDATE followed by AOC, replaces each `@language` path component with the detected game-language
folder, and records version `0.0.01` only after both installations succeed.

## Installation

1. Copy the WUHB to `/wiiu/apps/BO2-Unbound-HQ/BO2-Unbound-HQ.wuhb` on the SD card.
2. Start Aroma, then launch **Black Ops 2 Unbound HQ**.
3. Confirm that the app detects the correct game SKU, language, update, and matching AOC installation.
4. Accept the `0.0.01` update prompt and keep the console powered on during both downloads.

This beta modifies installed game files. Keep a recovery backup and a known-good way to
reinstall the official update and DLC before testing.

## Known limitations

- Universal routing still requires real-hardware validation for every supported SKU/language pair.
- Workshop access is intentionally disabled in this build while its online services are prepared.
