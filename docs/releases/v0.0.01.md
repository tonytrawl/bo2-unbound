# Black Ops 2 Unbound HQ v0.0.01 Beta

This is the first public beta for the USA release of Call of Duty: Black Ops II on Wii U
(title suffix `1010CF00`).

## Release assets

- `BO2-Unbound-HQ-v0.0.01.wuhb` — the Aroma homebrew application.
- `unbound-USA-0.0.01-update.zip` — files installed into the UPDATE title.
- `unbound-USA-0.0.01-aoc.zip` — files installed into the AOC title.
- `unbound-USA-0.0.01.manifest.json` — per-file sizes and SHA-256 values.
- `checksums.sha256` — hashes for release verification.

Both ZIP packages are required. They are separate because GitHub requires each release asset
to be smaller than 2 GiB. The HQ application downloads and verifies each component, installs
UPDATE followed by AOC, and records version `0.0.01` only after both installations succeed.

## Installation

1. Copy the WUHB to `/wiiu/apps/bo2-unbound-hq/BO2-Unbound-HQ.wuhb` on the SD card.
2. Start Aroma, then launch **Black Ops 2 Unbound HQ**.
3. Confirm that the app detects the USA game update and matching AOC installation.
4. Accept the `0.0.01` update prompt and keep the console powered on during both downloads.

This beta modifies installed game files. Keep a recovery backup and a known-good way to
reinstall the official update and DLC before testing.

## Known limitations

- Only the USA title is published in this release.
- Workshop comments, ratings, and user uploads are still preview-only.
- Other regional consoles can browse HQ but do not receive this core package.
